## Tier 2 — Data & Analytics

### 2.1 Country Boxscore Bar Chart
- New `#boxscore-hud` panel (bottom-right, above results HUD) with visual horizontal bars
- `loadBoxscore()` refactored from plain `<ul>` list to `.st-bar` chart: country label → colored fill track → count
- Fill width = `country.COUNTRY_TOTAL / maxTotal × 100%`, color per-country via `colorForCountry()`
- Auto-refreshes every 10 minutes alongside feed/decay-watch

### 2.2 Debris Field Visualization
- Altitude-banded orbital rings rendered as Cesium polylines with `PolylineGlowMaterial`
- Bands: 200km intervals from 200–2200km, alpha/width proportional to debris count per band
- Toggle button "DEBRIS" in catalog HUD — disabled when no debris objects are rendered
- Automatically cleared on `clearRendered()` and re-render filter

### 2.3 Launch Site Markers
- 80+ hardcoded launch site coordinates covering CCAFS, VAFB, KSC, Kourou, Baikonur, Plesetsk, Tanegashima, Xichang, Jiuquan, Sriharikota, Alcantara, Woomera, and more
- After `addObjects()`, unique `SITE` values from rendered objects resolved via fuzzy match against lookup table
- Rendered as Cesium `Entity` point markers with labels, `scaleByDistance` for zoom-responsive sizing
- Toggle button "SITES" in catalog HUD

### 2.4 Object Age Coloring
- `ageColor(row)` maps elset/launch age to a bright→dim gradient: recent = bright cyan (#00d2ff), old = dim grey
- Max age: 3 years, linear interpolation across RGB channels
- Toggle button "AGE" in catalog HUD, with `NEW → OLD` gradient legend
- Recolors all rendered points in-place; reverts to type/country mode on toggle off

## Tier 3 — Performance & UX

### 3.1 LOD System
- Camera height monitored on `camera.moveEnd`
- `> 5000km`: show all rendered objects (zoomed out)
- `< 500km`: sort by distance from camera, show closest 400 only (zoomed in)
- Between thresholds: show all — smooth transition, no pop-in

### 3.2 Time-Based Filtering
- "LAST 30 DAYS" preset: clears filters, sets `type=PAYLOAD`, queries `year_from=<current year>`, applies `renderWithEra()`
- "DECAYING NOW" preset: queries current month, filters results by `DECAY_DATE` within the calendar month
- Both presets available in desktop filters HUD and mobile filter drawer
- Active preset highlighted with `.st-preset-btn--active` class

### 3.3 Cross-Page State Sync
- `State.subscribe('preferences.colorMode', ...)` listener on catalog page
- When colorMode is changed on another page (future use), catalog page auto-updates and re-renders
- Existing `State.set('preferences.colorMode', ...)` on toggle already persists to localStorage

### 3.4 Screenshot / Snapshot Button
- Camera icon button fixed at bottom-right viewport
- Click: `canvas.toBlob('image/png')` → browser download as `spacetrack-YYYY-MM-DDTHH-MM-SS.png`
- Shift+click: copy to clipboard via `navigator.clipboard.write([new ClipboardItem(...)])`
- Fallback: opens image in new tab if clipboard API unavailable
- Visual feedback: button shows checkmark for 1.5s on successful clipboard copy
