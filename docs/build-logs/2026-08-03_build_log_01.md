## Brief (`public/spacetrack/brief/`)

### Boxscore bars
- **Root cause:** `loadBoxscore()` called `colorForCountry(row.COUNTRY)` — but the boxscore API returns `SPADOC_CD` (`CIS`, `PRC`, `UK`, …), a *different* code set from the GP `COUNTRY_CODE` keys the palette knows (`RU`, `CN`, `GB`, …). Every row except `US`/`FR`/`IT`/`CA` fell through to default grey, so the chart conveyed nothing.
- `public/theme/palette.js` gains `BOX_CD` (SPADOC → palette-key alias map, e.g. `CIS→RU`, `PRC→CN`, `UK→GB`, `SKOR→KR`) and `colorForBoxCode(code)` — null for the `TBD`/`ALL`/`ORB` pseudo-rows so they fall through to `COUNTRY_DEFAULT` instead of a wrong match. One color source: alias at the boundary, never a second copy of the palette.
- Bars are now **stacked segments**: orbital count colored, decayed count muted grey beneath — so the bar shows both `ORBITAL_TOTAL_COUNT` and `DECAYED_TOTAL_COUNT` per country without a second row. Legend swatches (ORBITAL/DECAYED) added in `index.html`; counts on `title` for hover.

### Degraded-artifact honesty
- `loadFeed` maps event kinds to `.st-feed__tag` chips (`kind-new`/`kind-decay`/`kind-predict`/`kind-change`) so the signal feed reads as new/decay/predict at a glance; legend swatches added.
- `loadDecayWatch` shows `built {relTime(generated_at)}` so the user can see how fresh the watch list is (it is a daily drop).
- Brief card: when the AI narrative is off / artifact missing, the API's `note` is rendered instead of a blank card.

## Analytics (`public/spacetrack/analytics/`)
