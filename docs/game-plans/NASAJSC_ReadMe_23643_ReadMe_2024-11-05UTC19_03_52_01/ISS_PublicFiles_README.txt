Greetings Space-Track user,

Please use these files for planning purposes only. For operational conjunction assessment, please defer to 18/19 SDS.
For an overview of the data included in Public Files for ISS, see below:

15Day - In this zip file there is a 15-day ISS ephemeris and sequence of events. This trajectory includes any translational manevuers,
mass/area changes, visiting vehicle traffic, and drag scaling during the span. These events will be noted in the Traj_Summary.txt file. 
Drag scaling is used to optimize the ephemeris for the next 3 days. As such, this ephemeris is updated every Monday, Wednesday, and 
Friday. Use this ephemeris for short-term planning. 

8Week - In this zip file there is an 8-week ISS ephemeris and sequence of events. This trajectory includes any translational manevuers,
mass/area changes, visiting vehicle traffic, and drag scaling during the span. These events will be noted in the topo52_STP_traj_summary.txt
file. Drag scaling is used to optimize the ephemeris for the next 4 weeks. This product has an accuracy requirement of 6 minutes acquisition
time error at 4 weeks. The ephemeris will be posted once a week no later than Wednesday. Use this ephemeris for long-term planning.
